# Pedidos de mudança compartilhada

Crie um arquivo `<id-do-agente>-<assunto>.md` aqui (modelo em `docs/INTEGRATION_GUIDE.md §5`) para pedir ao Integrador
mudanças em arquivos compartilhados (`src/core`, `src/app`, `package.json`, design system, tipos).
Este é o único lugar fora da própria área onde um agente pode criar arquivos.
